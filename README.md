# JALNYAY AI web app

This package is ready for GitHub Pages. It is a responsive, installable web app with local browser storage for demo accounts, complaints, service requests, alerts, priority data, and tanker tracking.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload the contents of this folder, including `.github` and `.nojekyll`.
3. Open **Settings → Pages** and set **Source** to **GitHub Actions**.
4. Open the **Actions** tab. The “Deploy JALNYAY AI web app” workflow runs automatically.
5. After it completes, open the deployment link. On mobile, open it in Chrome and choose **Install app**.
